# Install Kestrel in Claude Desktop (no terminal)

1. Install [Claude Desktop](https://claude.ai/download) and sign in.
2. Download **kestrel.mcpb** from the [latest release](https://github.com/evogr1/kestrel/releases/latest).
3. Double-click the file. Claude opens. Press **Install**. Leave every box empty.
4. In a new chat type: **Set up Kestrel**. The first start can take a minute.
5. Answer its questions: your niche, topics, the results you want, competitors and audience.
6. Try: **Find YouTube outliers about home cooking from the last 30 days.**

## Optional: free YouTube key (exact dates and channel sizes)

1. Open [Google Cloud Console](https://console.cloud.google.com) and sign in. No card needed.
2. Create a project, any name.
3. APIs and Services, Library: search **YouTube Data API v3**, press **Enable**.
4. APIs and Services, Credentials, Create credentials, **API key**. Copy it.
5. In Claude: Settings, Extensions, Kestrel, Configure. Paste it and save.

## Advanced: Instagram

Needs an Instagram Business or Creator account and your own free Meta developer app. Type **Set up Kestrel** and ask for Instagram; Claude walks you through it.

## ChatGPT

Not supported yet. ChatGPT cannot run Kestrel on your computer.
